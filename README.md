# SF-Motion

**Open-source BLDC/PMSM motor control platform based on STM32 and Field-Oriented Control (FOC).**

The project includes:

- FOC firmware
- Custom motor driver hardware
- KiCad schematic and PCB design
- Gerber and BOM files
- Python communication and control tools
- PyQt/PyQtGraph GUI for motor monitoring and testing

> ⚠️ This project is under active development. Hardware and firmware may change between versions.

## Hardware Prerequisites

You will need:
- FOC Driver Board
- ST-Link programmer/debugger with 3-pin Molex pico-blade P1.25mm connector
- DC power supply
- BLDC/PMSM motor
- diametrical magnet
- USB type-C cable
- power cable with XT-30 female connector

The hardware design is available in:
```
Hardware/
├── production/        # Gerber manufacturing files
├── .kicad_sch         # Schematic
├── .kicad_pcb         # PCB design
└── ...
```

## Software Prerequisites

### 1. STM32CubeMX

Used to configure the STM32 peripherals and generate the initial project configuration.

Download: https://www.st.com/en/development-tools/stm32cubemx.html

### 2. Visual Studio Code

Used as the main development environment.

Download: https://code.visualstudio.com/

### 3. PlatformIO

PlatformIO is used to build and upload the firmware.

Install PlatformIO through the VS Code extension:
1. Open VS Code.
2. Open Extensions.
3. Search for PlatformIO IDE.
4. Install the extension.
5. Restart VS Code if required.

Verify the installation:
``` bash
pio --version
```

If `pio` is not recognized in the terminal, use the PlatformIO terminal inside VS Code or add the PlatformIO CLI directory to your system PATH.

### 4. Python

Python is required for the communication tools and GUI.

Recommended version:
```text
Python 3.10+
```

Download: https://www.python.org/downloads/

Check the installation:
``` bash
python --version
```

Create a virtual environment (recommended):
``` bash
python -m venv .venv
```

Activate it on Windows:
``` bash
.venv\Scripts\activate
```

Activate it on Linux/macOS:
``` bash
source .venv/bin/activate
```

Install the required packages:
``` bash
pip install numpy pyserial PyQt5 pyqtgraph
```

## Getting Started

Clone the repository using Git:
``` bash
git clone https://github.com/sirojudinMunir/sf-motion.git
```

Enter the project directory:
``` bash
cd SF-Motion
```

## Building the Firmware

Open the project in VS Code with PlatformIO installed.

Build the firmware:
``` bash
pio run
```

If the build is successful, the firmware binary will be generated by PlatformIO.

## Upload Firmware

Connect the ST-Link to the FOC Driver board using the 3-pin PicoBlade connector.

The board can be powered from a **6–24 V external power supply**. For the initial test, it is recommended to use **USB Type-C** as the power source if applicable.

Upload the firmware:
``` bash
pio run -t upload
```

You can also use the Upload button in the PlatformIO interface in VS Code.

## For the first test

After uploading the firmware, follow these steps:

1. Make sure the D3 LED is blinking after the firmware starts.
2. Connect the BLDC/PMSM motor wires to the FOC Driver board. Make sure the diametrical magnet is securely mounted on the motor shaft and properly aligned with the magnetic encoder on the FOC Driver board. The board should be positioned directly beneath the magnet.
3. If you are using an external power supply, set the current limit to 1 A for the initial test. This helps prevent damage if there is an unexpected issue with the board or motor.
4. Connect the USB Type-C cable to the board.
5. Run the Python motor control program:
    ```python
    python communication/motor.py
    ```
6. Select the correct COM port and click Connect.

7. Before running the motor, set the correct motor pole pairs:
    ``` python
    motor.set_pole_pairs(<your_motor_pole_pairs>)
    ```
    Replace <your_motor_pole_pairs> with the actual number of pole pairs of your motor.
8. Run the self-commissioning process:
    ``` python
    motor.self_commissioning()
    ```
    The self-commissioning process measures the motor resistance and inductance and calibrates the magnetic encoder.
    >Important: During encoder calibration, make sure the motor rotates counter-clockwise (CCW). If the motor rotates in the opposite direction, swap any two motor wires to reverse the rotation.
    Automatic motor direction detection will be implemented in a future version.
9. Save configuration
    ``` python
    motor.save_config()
    ```
10. Test the FOC motor modes using:
    ``` python
    motor.set_foc_motor_mode(<mode>)
    ```
    Available modes:

    0 -> for current control mode  
    1 -> for speed control mode  
    2 -> for position control mode  
    5 -> for open-loop mode  
    6 -> for disable the motor

> ⚠️ Keep the power supply current limit low during the first test. Do not increase the voltage or current limit until the board, encoder, and motor are confirmed to be working correctly.
